# Seller Portal (`apps/seller`) — quy tắc riêng

> Đọc `CLAUDE.md` gốc repo trước. Doc tính năng: `documents/FunctionDescription/SellerPortal.md`. Kế hoạch: `documents/Plans/SellerPortal-NextApp.md`.

- **Next 16 App Router, React 19, Tailwind v4** (`@theme` trong `src/app/globals.css`, KHÔNG có tailwind.config; pin `tailwindcss`/`@tailwindcss/postcss` **4.3.1** — bản 4.0.x vỡ với Turbopack `Missing field negated`). Khuôn giao diện clone từ thghub: kit `src/components/shared/*` tự viết, **không shadcn/radix**, không form lib.
- **Cổng 3017** (`next dev|start -p 3017`). 3100 của thghub đã bị dự án khác trên hub chiếm. `next start` KHÔNG đọc `.env.development` → chạy prod/dev-hub phải truyền `API_INTERNAL_URL`/`NEXT_PUBLIC_*` qua môi trường (systemd/pm2), `.env.development` chỉ cho `next dev`.
- **KHÔNG Prisma, KHÔNG server action, KHÔNG gọi thẳng API từ browser.** Mọi dữ liệu đi qua proxy same-origin `src/app/api/v1/[...path]/route.ts` → NestJS (`API_INTERNAL_URL`), proxy tự gắn `Authorization: Bearer` từ cookie httpOnly `onos_seller_token`. Client dùng `useApi()`/`apiFetch()` (`src/hooks/use-api.ts`) với URL tương đối `/api/v1/customer/...`; phản hồi luôn là `{ success, data, total? }` (`ApiRes<T>` ở `src/lib/customer-orders.ts`).
- **Endpoint BE cho seller phải nằm dưới `customer/`** (`apps/api/src/guards/roles.guard.ts` chỉ cho vai Customer vào prefix này); route public dùng `public/...`. Thiếu số/field → thêm ở BE + `packages/shared`, không tính ở FE.
- Từ `shared`: **`import type`** cho DTO; giá trị runtime (enum) import từ **`shared/enums`** (subpath không kéo `@nestjs/common` — đã kiểm: 0 chunk client chứa `@nestjs`). Cần Zod runtime (validate CSV) → `dynamic()` riêng trang đó. `tsconfig.json` có `paths` cho `shared`, `shared/enums`, `@shared/*` (mã nguồn shared dùng alias `@shared/…`; thiếu path là mọi DTO thành `any`).
- **Server Component (root `layout.tsx`, route handler, `proxy.ts`) KHÔNG được import `@/i18n`** (kéo `react-i18next` → `createContext` vỡ lúc build). Hằng dùng được ở server nằm ở `src/i18n/constants.ts`.
- Trục phân loại đơn = **dòng sản phẩm** `productLine` (`3d · 2d · wood · embroidery · led · canvas`, `src/lib/product-lines.ts`), KHÔNG phải `printMethod`. Route `/portal/orders/<line>` khoá tab qua prop `lockedLine` của `OrdersListView`.
- i18n: `react-i18next`, JSON `src/i18n/locales/{vi,en}/*.json`. Namespace `customerPortal`/`track`/`common` **copy từ `apps/web` bằng `pnpm sync-i18n`** (tự chạy ở `prebuild`); sửa khóa ở `apps/web` trước rồi đồng bộ sang, KHÔNG sửa tay bản copy. Namespace riêng của app: `seller.json`. Nhãn enum shared → dictionary FE (`customerPortal.productLines.*`).
- Lint dùng rule React Compiler (`react-hooks/set-state-in-effect`): không `setState` đồng bộ trong effect — tải dữ liệu qua SWR/`useApi`, đồng bộ state theo khuôn "adjust state while rendering" (xem `orders-list-view.tsx`, trang chi tiết đơn).
- Mọi page là client component (`'use client'`) như thghub; root layout server chỉ bọc providers và đọc cookie `onos_lang`.
- Không hardcode màu ngoài token `@theme`; bảng màu lấy từ **logo ONOSPOD** (`public/onos-logo.svg`): accent hồng cánh sen `#c40c68`, CTA `#a80a58`, success/warning/error = xanh/vàng/đỏ của logo (SellerPortal.md §4). Màu ngữ nghĩa (trạng thái/dòng sản phẩm) ở `src/lib/constants.ts` + `src/lib/product-lines.ts`, dùng kèm alpha `color + '15'`.
- Responsive bắt buộc: bảng dữ liệu phải có bản THẺ dưới `md` (mẫu `components/orders/order-card.tsx`), header/toolbar xếp dọc dưới `sm`; kiểm ở 390 px trước khi giao.
- **Chạy `pnpm --filter ./apps/seller e2e` sau MỌI thay đổi giao diện** (`apps/seller/e2e/run.mjs`, Playwright dùng bản có sẵn ngoài workspace qua `PLAYWRIGHT_PATH`). 43 kiểm tra phủ luồng chính seller + hub và **những chỗ đã từng hỏng vì làm tính năng mới**: cột mã đơn cố định ở cả hai bảng (thêm cột tick từng đẩy nó văng đi), catalog không 500 (kiểu `printArea` sai từng làm chết cả trang), cột Nội bộ và cột vận đơn còn nguyên, nút mua label + chọn hàng loạt, phễu 8 chặng, bộ lọc ngày dạng pill. Đổi môi trường bằng `E2E_BASE`, tài khoản bằng `E2E_SELLER_*` / `E2E_STAFF_*`.
- **Khung cố định trên laptop**: shell `/portal` và `/hub` là `lg:h-screen lg:overflow-hidden`, `main` là vùng cuộn DUY NHẤT. Màn nhiều cột dựng bằng `lg:h-full` + cột tự cuộn, nút hành động chính neo đáy cột (`lg:shrink-0`) — không để nút rơi xuống dưới đáy trang. E2E chốt ở 1440×900 và 1366×768.
- **Vai staff ở `/hub` KHÔNG gọi được `customer/*`** (token nhân viên → 401, và 401 đá người dùng về trang đăng nhập). Component dùng chung giữa hai vai phải nhận đường API theo vai (mẫu: `catalogBase` và `designApi` của `CreateOrderView`), BE cấp bản sao dưới `admin/...` nạp khách theo `customerId`.
