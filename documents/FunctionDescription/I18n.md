# I18n (Đa ngôn ngữ) — Function Description

> **File FE:** `apps/web/src/i18n/index.ts`, `apps/web/src/i18n/locales/{vi,en}/*.json`, `apps/web/src/store/languageStore.ts`
> **Wiring:** `apps/web/src/main.tsx` (init + dayjs locale ban đầu), `apps/web/src/components/header/index.tsx` (nút chuyển ngôn ngữ), `apps/web/src/layouts/customerLayout/CustomerLayout.tsx` (nút chuyển ngôn ngữ riêng cho Customer Portal)
> **Route:** không có route riêng — cross-cutting, áp dụng toàn bộ `apps/web`
> **API:** không có endpoint BE — thuần FE, không đụng `packages/shared`/BE

---

## 1. Overview

Toàn bộ text hiển thị người dùng trong `apps/web` đi qua **react-i18next**, hỗ trợ 2 ngôn ngữ: **Tiếng Việt (mặc định)** và **English**. Người dùng đổi ngôn ngữ qua nút ở Header (nhân viên, `/adm` + `/ffm`) hoặc `CustomerLayout` (Customer Portal, `/customer`) — lựa chọn persist qua `localStorage` (`printsel-language`, cùng pattern với `printera-theme` của `themeStore.ts`).

Đây là hạ tầng **cross-cutting**, không thuộc 1 feature cụ thể — mọi trang/component khi sửa đổi cần tuân thủ quy tắc bên dưới thay vì hardcode string mới.

## 2. Kiến trúc

### 2.1 Namespace theo feature

Translation JSON tách theo **namespace = tên feature**, khớp với bảng "Feature → Doc mapping" ở `CLAUDE.md` gốc:

```
apps/web/src/i18n/
  index.ts                 # init i18next, import tĩnh + đăng ký mọi namespace
  locales/
    vi/{common,auth,layout,dashboard,orderLifecycle,orders,orderLog,scanError,
        stageErrorCatalog,designerTaskWorkflow,fulfillmentWorkflow,toolCheckWorkflow,
        products,promotion,workshopConfig,designerAutoAssign,
        customerFactoryAssignment,customerPortal,landing}.json
    en/ (mirror cấu trúc trên)
```

- `common` — string dùng chung toàn app: `actions.*` (Lưu/Hủy/Xóa/Sửa/Tìm kiếm...), `status.*`, `confirm.*`, `table.*`, `pagination.*`, `datePresets.*`, `dateRange.*`, `multiSelect.*`, `selectFilter.*`, `imagePreview.*`, `errors.*` (404), `language.*`.
- `layout` — Sidebar + Header (menu nhân viên, không phải Customer Portal).
- `auth` — Login/Register/ForgotPassword/Account + `permissions.*` (dictionary label permission-catalog, xem §2.3) + `permissionGroups.*` + `roles`/`users`/`departments`/`customRoles`/`settings`.
- Các namespace còn lại map 1-1 với feature tương ứng trong bảng mapping gốc.

**Quy tắc thêm namespace mới:** tạo file `{vi,en}/<name>.json`, import + đăng ký trong `resources` object ở `src/i18n/index.ts` (thêm vào cả object `vi` và `en`, `ns` tự suy từ `Object.keys(resources.vi)`).

### 2.2 Language store — mirror `themeStore.ts`

`src/store/languageStore.ts`: zustand + `persist` (key `printsel-language`), giá trị `'vi' | 'en'`. Action `setLanguage`/`toggleLanguage` gọi đồng thời:
1. `i18n.changeLanguage(lang)` — đổi resource resolve.
2. `dayjs.locale(lang)` — đổi format ngày tháng tương đối (dayjs có sẵn locale `en`, chỉ `vi` cần `import 'dayjs/locale/vi'` — đã có ở `main.tsx`).
3. `document.documentElement.lang = lang`.

`src/i18n/index.ts` export `getStoredLanguage()` đọc trực tiếp `localStorage` (không qua React) để `main.tsx` set `dayjs.locale` + `<html lang>` NGAY khi app load, tránh flash sai ngôn ngữ — cùng kỹ thuật với `themeStore.ts` áp class dark mode sớm.

### 2.3 Label có nguồn gốc từ `packages/shared`

Một số label hiển thị lấy trực tiếp từ constant trong `packages/shared` (dùng chung BE) — **KHÔNG sửa file shared** (rủi ro ngoài phạm vi FE, ảnh hưởng BE). Thay vào đó, FE tạo dictionary translation riêng khoá theo `code`/enum value, dùng `t(key, { defaultValue: originalLabel })` để tự fallback về label gốc nếu thiếu key:

| Nguồn shared | Dictionary FE | Helper |
|---|---|---|
| `permission-catalog.ts` (`PERMISSION_CATALOG[].label`, 63 permission) | `auth.json` → `permissions.<code>` | inline `t(\`permissions.${code}\`, { ns: 'auth', defaultValue: item.label })` trong `components/roles/PermissionMatrix.tsx` |
| `fulfillment-stage.ts` (`FULFILLMENT_STAGE_LABELS`, 6 stage) | `fulfillmentWorkflow.json` → `stageLabels.<stage>` | `apps/web/src/utils/fulfillmentStageLabel.ts` → `getStageLabel(t, stage)` |
| `product-print-area.ts` (`PRODUCT_PRINT_AREAS[].label`, 18 vị trí in) | `products.json` → `printAreas.<key>` | inline `t(\`printAreas.${pa.key}\`, { defaultValue: pa.label })` trong `pages/products/detail/index.tsx` |

`getStageLabel()` gọi được từ **bất kỳ component nào** bất kể namespace mặc định của `t` (luôn truyền `{ ns: 'fulfillmentWorkflow' }` tường minh) — nhiều trang dùng chung 1 stage picker/label (Dashboard, Orders, Fulfillment, Users) nên không thể ép cùng 1 namespace mặc định.

### 2.4 Quy tắc convert code (bắt buộc khi thêm string mới)

1. Component: `const { t } = useTranslation('<namespace>')` (hoặc mảng `[ns1, ns2]`), thay literal bằng `t('key')`.
2. **Map/mảng label khai báo module scope** (ngoài function component — chỉ evaluate 1 lần lúc import, KHÔNG tự đổi khi user chuyển ngôn ngữ) → chuyển thành **function nhận `t` làm tham số**, gọi trong component qua `useMemo(() => buildX(t), [t])`. Ví dụ mẫu: `buildNavGroups(t)` (`Sidebar.tsx`), `buildStatusMeta(t)` (nhiều nơi).
3. **Zod schema có message lỗi** khai module scope → factory function `buildXSchema(t)`, gọi qua `useMemo` trong component. Ví dụ: `buildLoginSchema(t)` (`pages/login/index.tsx`).
4. Module KHÔNG phải React component (vd `apis/index.tsx` interceptor, `pages/home/exportOrders.ts`) → import trực tiếp `i18n` default export từ `@/i18n`, gọi `i18n.t(key, { ns })` (đọc đúng ngôn ngữ hiện tại tại thời điểm gọi, không cần hook).
5. Component dùng chung nhiều nơi nhưng chỉ nhận `t` optional (để không phá vỡ các call site cũ) → tra namespace tường minh qua `{ ns: 'orders' }` bên trong hàm thay vì dựa vào namespace mặc định của `t` truyền vào (xem `utils/priorityEstimate.ts`, `utils/fulfillmentStageLabel.ts`).

## 3. UI Components

- **Nút chuyển ngôn ngữ (nhân viên):** `components/header/index.tsx`, icon `Languages` (lucide-react) cạnh nút dark/light mode, hiện mã ngôn ngữ hiện tại (`VI`/`EN`).
- **Nút chuyển ngôn ngữ (Customer Portal):** `layouts/customerLayout/CustomerLayout.tsx`, cùng pattern.
- Cả 2 gọi `useLanguageStore().toggleLanguage()`.

---

## 4. Performance notes

- Toàn bộ resource JSON **bundle tĩnh** vào JS bundle (import trực tiếp trong `i18n/index.ts`), không lazy-load qua HTTP backend — phù hợp quy mô app hiện tại (~20 namespace, mỗi file vài KB), tránh network waterfall khi đổi ngôn ngữ.
- Đổi ngôn ngữ không reload trang — `i18n.changeLanguage()` trigger re-render qua `initReactI18next` subscription, tức thời.
